## 待真机验收与后续边界

当前没有提供实际 GPU 节点地址或模型权重环境，尚未进行真实 Docker/vLLM 单卡、多卡、断网重启和模型显存校准。按 [Agent 接入手册](../agent/README.md) 登记节点，再执行 [真机矩阵](08-roadmap-testing.md#真机验收矩阵)。代码和协议通过不代表模型一定能在某型号上启动。

镜像仅支持不可变 digest；模型只支持固定白名单参数；多卡要求同机同型，拓扑互联仍需运维验证。仍采用单 API / SQLite，扩容前迁移共享数据库与协调机制。四语言正式对外发布前建议母语审校。

自动成本来源仍依赖实际设施接口；运维告警已交付，见下文。预约的最新交付记录见下文。Stripe 和 SMTP 适配已完成，渠道验收待环境配置；目前没有可用 GPU 验收节点。
