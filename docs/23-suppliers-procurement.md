# 第三方 GPU 接入、采购与结算

v12 支持供应商独立注册与管理自己的 GPU 节点，平台统一销售 Token 和按 GPU 卡时长出租。第一版按供应商设置统一固定采购价（微元/GPU·小时），所有销售价格由平台设置；不按用户消费金额分成。混合 GPU 型号需要分别约定采购价时，后续扩展到节点级价格，当前同一供应商统一价格。

## 流程与权限

供应商在自己的入口注册，初始状态 pending。供应商可登记、编辑、查看自己的服务器和实际 GPU、轮换自己的 Agent Token；不能访问其他供应商节点、管理员 API、客户数据、客户钱包或自行部署付费环境。客户业务由用户端承担，模型配置、销售定价、部署与停止由管理员管理。

平台在“供应商管理”审核账户、配置固定采购价，再审核在线节点。节点必须有完整 GPU 清单、有效 Agent 能力及独立密钥，且物理 UUID 不能与现有可信节点或活跃分配冲突。未审核节点不能进入销售与 Token 路由；供应商修改配置或 GPU UUID 清单变化后撤销节点审核。未审核库存不能隔离其他可信节点，防止重复 UUID 声明影响既有服务器。

供应商账户暂停或撤销节点审核阻止新销售/推理路由，但不会删除活跃分配、退款或已经发生的采购成本。已有 Jupyter 环境继续受原到期和清理协议约束。要结束采购应由平台停止部署并确认回收；离线、无健康响应和超时都不等于资源已回收。

## Agent 与节点密钥

Linux + NVIDIA + Docker，使用 Go Agent。供应商必须配置 COREMATRIX_NODE_SCOPED_KEYS=1（5-go），COREMATRIX_URL 指向**用户端控制面**的 HTTPS origin，Agent 接口不在供应商端口。管理注册返回的一次性 node_ Token 只写入该节点的私密环境文件。

认证心跳仅向该节点返回两把独立运行凭证：推理、Jupyter。服务端以该节点私有 seed 和用途派生；Agent 在首次任务领取前校验并安装至保留环境变量。其他节点的密钥、平台全局密钥不下发，管理/供应商 DTO 不包含 seed 或运行凭证。轮换 Agent Token 不更换运行密钥，避免中断已有工作区。旧自有节点兼容 4-go 与原 INFERENCE_* 环境变量；旧供应商 Agent 不能通过审核。

供应商主机管理员本身能控制硬件、容器和本节点凭证，平台审核仍需信任节点经营者；这不提供机密计算或对恶意宿主机的保护。外部推理仍按受控允许列表使用原渠道密钥，不向第三方节点分发。

## 固定采购口径

当前采用平台实际使用的 GPU：部署健康检查通过、进入 ready 时开始采购；Token 模型即使没有请求也按已占用 GPU 计费。部署排队或启动失败且从未就绪时不产生采购费用。滚动切换中新旧实例同时占用的时间分别计费。

首次 ready 原子保存 deploymentId、供应商、GPU 数、采购单价、资源名和 startedAt。价格之后的修改仅影响新部署，重复健康检查不重复开账。续费延长同一运行区间，不重新锁价；用户提前退租退款遵循原销售协议，不抵减实际采购卡时。

stop 任务成功且最新库存确认容器不存在、无未完成请求时，原子关闭采购区间并回收资源。采购持续到确认时刻，包括排空、离线和清理延迟，平台承担该阶段成本。按完整秒计量：

```
卡秒 = floor((endedAt - startedAt) / 1000) × GPU 数
采购金额（微元）= floor(卡秒 × 每 GPU 小时微元单价 / 3600)
```

单区间只向下舍入一次到微元。不按小时向上凑整；不足一秒不计。运行中按当前时间预估并单独展示，尚不可结算；确认关闭后成为应付款。服务重启不丢失开始时间，不因调价或心跳失联重开区间。平台财务自动计入关闭费用和运行预估，按 Asia/Shanghai 业务日拆分累计金额，跨日加总与总额一致。

采购账与客户消费账独立：平台可出现无收入、有采购成本的时段，毛利可能为负。结算支付不再重复记为成本，也不会修改用户余额。设备、电费等额外费用仍按原成本单据录入，供应商采购不得重复录入人工成本。

## 结算与数据契约

供应商账单显示累计采购卡时、总费用（含运行预估）、可结算、运行中预估、已付，以及按区间的 GPU 数、价格、时间、金额；区间每页 50 条，结算记录最近 100 条。第一版只登记**已经完成的线下付款**，管理员填入唯一付款凭证、说明和页面可结算总额；金额变化拒绝结算，凭证重复请求不重复入账。未接入自动转账、Stripe Connect 或银行付款。

| 表 | 用途 |
| --- | --- |
| users.accountType | 区分供应商与客户；管理员保留原 role |
| providers | pending/approved/suspended、固定采购价、审核管理员与时间 |
| provider_nodes | 节点归属、审核状态、已核准的 GPU UUID 清单 |
| servers.credentialSeed | 仅服务端保存的节点运行密钥 seed |
| provider_usage | 每部署唯一的采购区间、价格/卡数快照、关闭金额、结算关联 |
| provider_settlements | 已付总额、唯一凭证、说明、管理员与时间 |

GET /api/provider/profile、/billing、/servers：供应商自己的信息、账单及节点。POST /servers 登记自己的节点，PUT /servers/:id 编辑并撤销审核，POST /servers/:id/token 轮换凭证，DELETE /servers/:id 仅在无资源占用时删除。供应商提供的归属、审核、销售价格和销售开关不被采信。

GET /api/admin/providers 列出供应商、账单汇总与节点。PUT /api/admin/providers/:id 配置 {status,ratePerGpuHour}，采购价为 0–100000000000 整数微元。POST /api/admin/provider-nodes/:id/approval 配置 {approved}。GET /api/admin/providers/:id/billing 分页账单，POST /api/admin/providers/:id/settlements 接收 {amount,reference,reason}，记录已付。写操作均要求相应身份、CSRF 和同源校验。

迁移 v12 在事务中增加表和字段，原有账号密码、余额、订单和消费账本保留。升级前备份；数据库只运行一个写实例。对账增加采购金额重算、确认回收及付款关联金额校验。测试覆盖固定价快照、两种工作模式、独立节点密钥、跨日舍入、续费退款与采购独立、重复结算和供应商越权。真机、多卡、实际支付/邮件及真实结算凭证验收仍待实际环境。
