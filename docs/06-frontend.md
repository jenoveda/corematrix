# CoreMatrix 前端页面规范

沿用已确认原型的双端布局：顶部平台切换、左侧导航、主内容区、表格和操作弹窗。继续使用 React、TypeScript、Vite、lucide-react 与现有组件，不为新模块创建另一套设计系统。

## 页面与权限

| 路由                   | 当前状态                                           | 交付与验收边界                             |
| ---------------------- | -------------------------------------------------- | ------------------------------------------ |
| `/#/user/models`       | 真实模型、可调用状态、JSON/SSE 试用                | 实际推理服务兼容性待部署验收               |
| `/#/user/compute`      | 真实资源池、卡数/小时购买、订单和 Jupyter 入口     | 语言切换保留参数，网络结果未知使用原键重试 |
| `/#/user/keys`         | 创建、撤销、预算和四语言                           | 凭证明文仅本次展示                         |
| `/#/user/wallet`       | 余额、结构化账单、类型筛选、游标加载历史           | 每页 50 条本人记录，保留现有接口兼容       |
| `/#/user/account`      | 注册、登录、退出、偏好、验证/找回邮件              | 真实 SMTP 投递待验收                       |
| `/#/admin/overview`    | 收入、模型、节点、GPU 与部署阶段汇总               | 状态来自最近刷新，真实 GPU 性能待验收      |
| `/#/admin/servers`     | 列表、添加/编辑、详情、Token、维护及 UUID 冲突提示 | 真实 GPU 库存需接入节点                    |
| `/#/admin/deployments` | 创建、切换、停止、进度、事件与重试清理             | UI 不以 202 或计时器声称部署成功           |
| `/#/admin/pricing`     | 模型 CRUD、价格、人工入账、路由和运行模板          | 真实模型参数需校准                         |
| `/#/admin/reports`     | Token/GPU 净收入、成本、期间、作废、分页与对账     | 毛利限已录入成本口径                       |

访客访问私人页面展示登录入口；普通用户进入 admin 路由展示无权限。后端仍必须鉴权，前端菜单隐藏不是权限边界。

## 全局数据与刷新

管理概览从现有管理员 State 汇总已登记节点及 online/pending/offline/disabled、维护与库存/运行环境异常数量。GPU 总量和已分配量按物理 UUID 去重，缺失库存不计入总量，未释放占用仍计入已分配，可调度量沿用服务端资格判断。部署按全部阶段展示数量（含零值及停止记录），链接进入服务器和部署页，刷新按钮更新快照。就绪阶段计数用于观察生命周期；模型可调用状态遵循健康和路由判断。

继续使用 AppContext 的 state、refresh、mutate、notify。金额、权限、GPU 占用和部署状态只从服务端取得，不在浏览器自行计算后写回为真实状态。

当前路由切换和窗口重新聚焦会刷新 State。服务器和部署页面在可见期间每 10 秒刷新，隐藏时暂停；离开页面清理定时器。使用请求序号或取消信号避免旧响应覆盖新状态。

变更接口成功后刷新；若变更已成功而刷新失败，应显示“操作已完成，数据刷新失败”，不把提交按钮变成再次创建资源的自动重试。

## 服务器页面

### 列表

显示节点名称、区域、在线状态、最后心跳、GPU 数量、已分配、外部占用、空闲和异常数量。维护、禁用与离线分开标记。资源数量未知时显示“—”，不要显示 0 卡造成误解。

空状态提供“添加服务器”；加载失败保留上次数据和更新时间，同时显示错误与刷新入口。节点离线不显示“空闲全部 GPU”。

### 添加表单

字段为 name、region、inferenceHost、portStart、portEnd。提交后显示服务端生成的节点 ID、一次性 Agent Token 和接入说明。

Token 明文仅存当前弹窗内存；关闭后列表只显示凭证已配置。支持复制，并在复制失败时提供手动复制。用户可轮换 Token，界面说明旧 Agent 需要更新凭证。

### GPU 详情

每卡显示 UUID、index、型号、总显存、已用显存、利用率、温度、分配对象和采集时间。未知传感器显示 N/A 的本地化文案。库存缺失、外部计算进程、平台占用和可调度是不同状态。

不把 GPU 显存使用量的进度条标为计费进度，也不以绿色利用率条证明 GPU 可分配。

### 节点编辑与删除

名称和区域可改；改变主机或端口范围需后端确认没有活跃占用。进入维护仅禁止新部署；禁用会停止新的部署和推理接入，界面必须说明差别。

删除前展示受影响部署；后端 409 时保留页面和原因，不做乐观删除。

## 钱包历史

钱包交易明细每页请求 50 条，加载更多使用服务端游标。类型筛选查询全部本人历史；刷新回到最新一页，新账单随全局刷新进入列表。切换语言保留已加载页和筛选，不重复查账。请求序号屏蔽旧筛选/旧账号的晚响应，数据同时按 ownerId 和 filter 绑定；加载失败保留当前记录和游标，显示本地化错误并允许重试。完整 API 契约见 [钱包接口](04-api.md#已实现钱包和-key)。

## 模型管理页面

在已有配置表单中增加 routingMode。external 显示已有完整推理 URL；managed 显示运行模板，包括 artifact、revision、dtype、maxModelLen、minGpuMemoryMiB、GPU 数量及单卡需求。

GPU 的现有 vram 展示值不能替代 minGpuMemoryMiB。表单提供单位说明，并明确“资源模板需要真机校准”。任何字段默认值都不能暗示某型号一定满足内存需求。

模型的 enabled 上架开关与就绪部署数并列显示。删除存在部署的模型时展示 server 返回的 model_in_use，并提供部署页入口。

## 部署页面

### 创建

先选模型，再选可调度节点和 GPU UUID。选择器展示每卡实际显存及不可选原因。节点或模板变化后重新校验选择，防止保留已经不合法的 UUID。

提交时展示模型版本、节点、卡数、实际显存要求和滚动切换策略。请求使用创建时生成的 Idempotency-Key；网络结果不确定时保留同一个 Key 重试，不重复创建。

服务器不在线、资源不足或模板未配置时禁用提交，并给出对应字段原因；后端仍是最终校验来源。

### 列表和详情

显示模型、版本、节点、GPU UUID、phase、desiredState、健康时间和错误摘要。ready 才标“就绪”；checking 不是成功。

详情事件按时间展示 queued、starting、checking、ready、draining、stopping、stopped、failed/unknown。失败事件保留原始技术摘要，但界面状态标签按当前语言翻译。

### 切换

从旧实例进入“切换模型”表单，自动带入 replaces。确认时说明新旧模型、独立 GPU 需求、旧模型最后实例退役后的影响。

资源不足直接展示冲突；不出现隐式“停止旧模型并强行部署”按钮。新实例失败时显示旧服务仍在运行，新实例清理中或已清理。

### 停止与清理

停止先显示 draining，再显示 stopping，只有容器确认退出才 stopped。失败或 unknown 时展示“占用尚未释放”，提供查看事件与重试清理，不以任务超时显示成功。

## 语言切换

顶部平台切换附近提供语言选择：简体中文、English、日本語、한국어。选择语言不改变平台、路由或模型 ID，也不刷新整页丢失表单内容。

所有本产品固定文案，包括空状态、错误、权限、确认框、复制反馈、加载中、状态标签和无障碍标签，都进入翻译资源。具体优先级和字段格式见 [国际化](10-i18n.md)。

## 错误与可访问性

输入有可关联 label；弹窗使用原生 dialog，支持焦点约束与关闭后恢复焦点。涉及写操作时显示提交中状态并防止双击；后台任务进度不阻塞浏览器。

错误优先定位字段，操作失败提供可识别错误码。未知错误给出本地化通用提示和请求 ID，不直接向普通用户泄露节点内网地址或密钥变量内容。

375px 窄屏下按钮、表单、语言菜单和弹窗不溢出。日语、韩语及较长英文按钮需允许换行，不能依赖固定中文字符长度。

## 代码落点

新增独立 `src/pages/ServerPages.tsx`、`src/pages/DeploymentPages.tsx` 等模块按复杂度决定；现有 AdminPages 可以保留入口。翻译实现路径按 [国际化](10-i18n.md) 统一，避免页面各写一个语言切换逻辑。

任务 UI 不自行根据时间推断成功。所有状态转换、费用和资源释放由 API 决定，前端仅显示。

订单操作列固定在右侧，桌面和手机无需横向滚动即可找到续费/退租；总时长列展示累计小时，续费上限按未来剩余期限计算。

## 预约页面更新

独享算力原购买表单支持未来时段开关、明确 UTC+8 的日期输入、卡数/时长和报价上限，切换四语言保留草稿。未知响应保存原请求参数和键，刷新后可原单重试，存储不可用时不发起购买。用户预约列表与交付订单关联；服务器管理页新增预约计划、管理员 UUID/端口详情及带理由的取消。规则见 [预约契约](17-gpu-reservations.md)。

## 运维页面增量

/#/admin/operations 展示检查状态、未恢复/待确认计数、三组 HTTP 指标、50 条分页告警与恢复历史、最近 50 条邮件状态和失败重试。确认保留首位操作者，不清除仍存在的异常；SMTP 接受与邮箱实际送达区分显示。四语言与 375px 已验证。详见 [运维契约](18-operations-alerts.md)。

## 校验与错误详情增量

所有页面复用 ApiError 和四语言错误 formatter，按规范 field、min/max、资源与本人余额缺口显示提示，并显示合法请求 ID。未知详情不原样插入 UI。原生表单的长度、上下限、步长和类型提示跟随语言更新；切换语言保留草稿和业务幂等请求。详见 [国际化错误契约](10-i18n.md#错误详情交付记录2026-10-16)。
