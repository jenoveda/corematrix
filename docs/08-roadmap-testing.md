# CoreMatrix 开发计划和验收

后续按“国际化基础 → 节点资源 → 执行和路由 → 商业交付”的依赖顺序实现。每项任务必须有可复现的检查结果；配置表单、假进度或接口 202 不能代替容器已经就绪的验收。

## 已有基线

已实现账号、角色、模型 CRUD、外部网关、Token 预留结算、人工入账、API Key 和双端界面。新增国际化和部署测试；数量以实际 `npm test` 和 Agent unittest 输出为准。

I01–I05、S01–S05 与 D01–D07 的代码及协议测试已交付，含字段/范围/资源详情和原生校验切换。D04 的真实单卡/多卡启动及 D08 真机验收尚未完成。下面保留任务与验收清单，不以协议测试代替硬件验收。

## 完成定义

每个功能交付必须包含可运行代码、数据库升级、鉴权与输入验证、用户可见的失败状态、必要测试、四语言资源和更新文档。

下一阶段整体完成条件：管理员从零登记节点，Agent 上报 GPU，成功部署真实模型，用户通过已有计费网关获得真实回复，切换模型不破坏在途请求，停止后资源可再次安全分配。另需通过权限、并发和重启测试。

## 文档变更规则

状态枚举、接口字段和价格单位只有一个语义。更改任一项时同时更新 API、数据库、Agent、前端和测试文档；更新实施状态表时必须有对应代码和检查记录。
